# Relationships

Documento para explicar relaciones importantes del modelo.

- Un CRIT tiene muchas clínicas.
- Una clínica tiene muchos cuartos.
- Un colaborador puede pertenecer a varias clínicas.
- Una cita pertenece a un paciente, colaborador, clínica y cuarto.
- Una cita puede generar un registro de asistencia.
- Una asistencia puede tener nota médica.
